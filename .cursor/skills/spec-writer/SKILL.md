# Spec writer
## Instructions
- Stable IDs: FR-### and NFR-###.
- Acceptance criteria in Given / When / Then, each referencing its FR ID.
- Every FR has at least one failure-case criterion.
- Never invent features not in docs/plan.md. Put anything unclear under "Open Questions".
- One concern per file. Link between spec files instead of duplicating content.
