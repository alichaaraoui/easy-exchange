# Implement from spec
Run only when the user types /implement-from-spec.
## Instructions
1. Read the given FR IDs and their acceptance criteria in specs/requirements.md.
2. State a short plan (files to touch) before editing.
3. Implement the smallest change that meets the criteria. Follow book-exchange-domain.
4. Write one test per Given/When/Then.
5. Run the tests and report pass/fail. Don't continue with failing tests.
6. List any spec gaps you hit instead of quietly deciding them.
